# Баланс 0.7 — сравнение с 0.6

Дата: 13 ноября 2026 года. Сравнены 40 000 автоматических партий: 2 версии × 2 режима обмена × 2 темпа действий × 5000 одинаковых seed. Это моделирование действий, не 40 000 человеческих игровых сессий. Эмулятор используется отдельно для проверки пользовательских сценариев.

## Метод

`BalanceProbe` действует только по открытым игроку данным: своей руке и своим карточкам. Приоритет — слово, которое можно завершить имеющейся рукой, затем частично заполненное слово. Неудачное действие означает, что среди фишек нет подходящего свободного места. Проверены действия раз в 2 и 3 секунды. В режиме обмена предлагается первый не подходящий к своим словам слог; закрытое предложение бота не читается. Крупье и переносы в этом сравнении не используются, поэтому результат не покрывает все стратегии. Бот использует штатную реализацию соответствующей версии.

«Полезный обмен» — полученная фишка покрывает ещё не обеспеченную рукой потребность своих пустых ячеек, измеренную непосредственно при обмене. Все обмены считаются в движке, включая немедленные. «Полезная раздача» — у полученного слога есть хотя бы одно подходящее незаполненное место; это более слабый критерий, не гарантия завершения слова.

## Принятые изменения

1. Стартовые шесть фишек обоих участников содержат комплект для одного случайного короткого слова своего стола; остальные четыре берутся из общего скрытого мешка. Число фишек и интерфейс без подсказок сохранены. Это убирает старт без возможности ударить.
2. При пополнении общий мешок содержит недостающие слоги: уже заполненные ячейки и фишки, которыми соответствующий игрок уже владеет, учтены. Излишек одного слога не добавляется просто из-за его присутствия в слове. При нулевой общей потребности используется исходная кратность слогов. Распределение остаётся случайным; нет подбора по HP, результату или отставанию.
3. Бот оценивает, может ли завершить слово всей своей рукой; не размазывает подходящие фишки по длинным словам без учёта недостающих частей.
4. В обмен бот отдаёт ненужный слог или лишний экземпляр нужного. Полученный слог не предлагает обратно шесть секунд. Это ограничение только стратегии бота, игрок обменивается без задержки.

Меньшее число обменов при более высокой полезности означает, что стало меньше кругового обмена теми же фишками. С обменом игрок собирает на 49% больше слов, чем без него в новой версии; следовательно, обмен остался полезной частью стратегии.

## Сохранённые требования и ограничения

Не изменены 1:30, одна новая фишка каждому каждые 10 секунд, шесть стартовых фишек, рука 12, прямой урон 2/3/4, победа по HP, скрытый обмен и отсутствие предварительной подсветки. При таком темпе выдачи паузы между доступными размещениями неизбежны: за матч у каждого не более 15 фишек без обмена. Увеличивать частоту выдачи без нового решения пользователя нельзя.

Результат показывает улучшение для двух конкретных автоматических стратегий, а не доказательство идеального баланса или интересности для всех возрастов. Разнообразие слов пока ограничено тремя исходными группами. Сценарии переноса и крупье проверяются регрессионно, но их стратегическая ценность не оценивалась в этих таблицах.

## Воспроизведение

Нужен JDK 17. Команды из корня проекта:

```powershell
javac -encoding UTF-8 -d build-balance-before tests/balance/baseline/Game.java tests/balance/baseline/Rules.java tests/BalanceProbe.java
java -cp build-balance-before BalanceProbe 5000
javac -encoding UTF-8 -d build-balance-after app/src/main/java/ru/serg/slogi/Game.java app/src/main/java/ru/serg/slogi/Rules.java tests/BalanceProbe.java
java -cp build-balance-after BalanceProbe 5000
```

Исходники прежнего движка сохранены только для сравнения, с добавленными счётчиками обмена. В Android-приложение они не включены. Полные числовые результаты находятся в `tests/balance/before.txt` и `tests/balance/after.txt`.

## Проверка сборки
APK 0.7 собран, подпись проверена. Регрессионные проверки, 200 проверок стартовых рук обеих сторон и 500 партий прошли. На Android 11 вручную собрана РУЧКА из стартовой руки: бот потерял 2 HP, слово заменилось на ВАТА. Бот также собрал слово и нанёс 2 урона. Точки и подсветка подходящих мест не возвращались. В журнале AndroidRuntime ошибок при проверке не обнаружено. Для пользователя открыта свежая партия.
