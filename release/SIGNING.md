# Подпись и обновления Словобоя

Пакет релизной ветки: `ru.slavikus.slovoboy`. Он отделён от прежнего debug-прототипа `ru.serg.slogi`: тестовый ключ старых APK не используется для выпуска.

Новый постоянный ключ создан по разрешению владельца. Файлы находятся в `.signing/` проекта, исключены из Git, а доступ к папке ограничен текущим Windows-пользователем и SYSTEM:

- `slovoboy-release.p12` — зашифрованный приватный ключ, alias `slovoboy`;
- `keystore.properties` — локальные параметры подписи, включая пароль. Это секретный файл.

Оба файла нужны для последующих сборок. Сохраните их вместе в защищённой резервной копии вне этого компьютера. Не включайте `.signing` в архив для RuStore, исходники общего доступа или переписку. В `release/signing-certificate.pem` находится только публичный сертификат, его можно передавать.

Для всех обновлений сохраняются пакет, ключ и alias; `versionCode` увеличивается. При потере ключа не генерируйте молча новый ключ для того же опубликованного пакета.

Пересборка с настроенными JDK 17 и SDK 35:

```powershell
$env:JAVA_HOME='путь к JDK 17'
$env:ANDROID_HOME='путь к Android SDK'
.\tools\Build-Release.ps1
```

Скрипт не печатает пароль и проверяет подпись APK. `1.0.0-rc3-update1` / код `106` — кандидат для тестирования и проверки владельцем. Для окончательного `1.0.0` после тестов рекомендуется увеличить код до `107` и обновить версию, описание и имена выходных файлов.
