# Словобой · V-Star Games

Слоговая дуэль для Android и мобильного браузера. Тестовая сборка **1.1.0-levels-rc8**, versionCode **114**.

- Фирменный знак по дизайн-системе V-STAR Group: лайм, тёмный сине-зелёный, Manrope. Заставка, меню и карта уровней.
- Громкость 0–100%, по умолчанию 100%; переключатель и уровень громкости сохраняются.
- Уровень игрока и опыт: +100 XP за победу. Для уровней 1/2/3 нужно 1/2/3 новых побед (суммарно 1/3/6). Поздравление при повышении.
- Уровень 1: точные правила RC3, 36 слов, раздача каждые 10 секунд.
- Уровень 2: расширенные правила, 360 слов, случайная выдача с предпочтением новых слов, ускорение по раундам. При пустой руке — фишка через секунду, затем обычный интервал. Таймеры сторон независимы.
- Слово наносит 1/3/5 HP за 2/3/4 слога и заменяется. Раунд 90 секунд, победа при нуле HP.
- Скрытый обмен, перенос, сброс, взаимная замена слов. Оба порядка выбора слота и фишки.
- Отдельные экраны победы и поражения, иллюстрации и звуки. Пауза оформлена в палитре игры.

[Играть в браузере](https://vstaroverov.github.io/slovoboy/) · [Скачать APK](releases/rustore/slovoboy-levels-rc8.apk). Правила и проверки — [LEVELS.md](LEVELS.md).

## Android

JDK 17, Android SDK 35 / Build Tools 35.0.0. Укажите JAVA_HOME и ANDROID_HOME.

~~~powershell
.\gradlew.bat :app:assembleDebug
.\tools\Test-Game.ps1
~~~

Для релиза: tools/Build-Release.ps1 с существующим локальным ключом. Приватная папка .signing не публикуется. UID сериализуемых классов сохраняются. В манифесте Android 6.0+; проверено на эмуляторах Android 11 и 15, реальный телефон требует проверки.

## Веб и iPhone

Интерфейс вписывается в экран без прокрутки; в горизонтальном положении слова и фишки размещаются в две колонки. Изменения — UPDATE3.md.

Готовые файлы в docs/ для GitHub Pages. Исходник веб-версии в web/dist/, тесты в web/tests/.

~~~powershell
cd web
node tests/parity.mjs
node server.mjs
~~~

Локально http://localhost:4173. На iPhone открывайте опубликованную HTTPS-страницу в Safari; «Поделиться → На экран Домой» добавляет иконку. Офлайн-ресурсы кэшируются после первой успешной загрузки. Реальный Safari ещё не проверен.

Публикация: GitHub Settings → Pages → Deploy from a branch → main → /docs → Save. Опубликовано 14.11.2026: https://vstaroverov.github.io/slovoboy/. Включён HTTPS. Игра, словарь, изображения и все звуки проверены по SHA256 опубликованных файлов.

## Данные

Без рекламы, аккаунтов, платежей и аналитики. Android сохраняет партию, историю слов, отметки побед и звук локально; веб использует localStorage и кэш ресурсов. Подробности — release/PRIVACY_POLICY.md. Очистка данных удаляет локальный прогресс. Лицензия MIT.
