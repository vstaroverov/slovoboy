# Словобой · RC3 · обновление 1

Офлайн-дуэль с ботом: собирайте слова из слогов, наносите урон и меняйтесь фишками вслепую.

Текущая сборка — **1.0.0-rc3-update1**, versionCode **106**. [Скачать APK для Android](releases/rustore/slovoboy-rc3-update1.apk). В манифесте Android 6.0+; эта сборка проверялась на эмуляторах Android 11 и 15.

## Игра

- 327 слов без одиночных букв в слогах; стол из трёх слов по 2 слога, двух по 3 и одного по 4.
- Заполненное слово сразу наносит 1 / 3 / 5 HP урона и заменяется новым.
- Фишку и пустой слот можно выбирать в любом порядке. Ошибка не расходует фишку; подсказок правильного ответа нет.
- Стартовая рука — 6 фишек, затем по одной каждому с интервалом 10/9/8/.../1 с по раундам.
- Раунд — 1:30. После таймера можно продолжить ту же дуэль. Победа или поражение — при нулевых HP.
- Слепой обмен, перенос слогов и замена слов по взаимному согласию по взаимной заявке.
- Короткие звуки выбора, установки, ошибки, удара, обмена и результата. «Звук: вкл/выкл» доступен до старта и на столе; настройка сохраняется.

Игровая основа — RC3, правила **3.4**. Новая дуэль начинается после двухсекундного отсчёта. Соперник переименован; замена карточки называется «Заменить слово», окно сброса оформлено в палитре игры. Полные правила — [RULES.md](RULES.md), изменения и проверка — [UPDATE1.md](UPDATE1.md), звуки — [SOUNDS.md](SOUNDS.md).

## Сборка и проверки

Нужны JDK 17 и Android SDK 35 / Build Tools 35.0.0. Укажите `JAVA_HOME`, `ANDROID_HOME` и локальный путь к SDK стандартным способом.

```powershell
.\gradlew.bat :app:assembleDebug
.\tools\Test-Game.ps1
```

Для подписанного выпуска владелец использует свой существующий ключ:

```powershell
.\tools\Build-Release.ps1
```

Параметры подписи находятся локально в `.signing/keystore.properties`; ключ и пароль не входят в репозиторий. Сохраняйте прежний ключ для обновлений. Подробности — [release/SIGNING.md](release/SIGNING.md).

Звуки синтезируются исходником `tools/MakeSounds.java`, без внешних семплов:

```powershell
javac -encoding UTF-8 -d build-sounds tools/MakeSounds.java
java -cp build-sounds MakeSounds app/src/main/res/raw
```
